# 수학비서 구독 PRD

내신·교재 DB 구독과 문제은행 구독의 기능 정의서입니다. 수학비서 B안 기준 검토안입니다.

[PRD 바로 보기](https://kj2286.github.io/mathsecr-subscription-prd/) · [B안 출처찾기·DB화](https://subscription-question-bank.vercel.app/?variant=b&revision=20260929-bank-source#source) · [문제은행](https://subscription-question-bank.vercel.app/?variant=b&revision=20260929-bank-source#bank)

DB 구독과 문제은행 구독은 각각 상품 단위입니다. 두 상품 모두 전체 학년을 이용하며, 학년은 검색 필터로만 사용합니다. DB 구독 제외 자료는 별도로 구분합니다.

## 문서 내용

- 내신·교재 탐색·개별 구매·상품 단위 구독·학교 알림
- 문제은행 검색·문항별 구매·숫자와 수식 미리보기 제한
- 업로드 문항별 출처 확인·복수 문항 구매·출처에 맞는 구독 안내
- 내 문제지의 여러 DB 선택·랜덤 출제·문제지 저장
- 구독 신청·상품별 권한·해지·만료·재구독
- 완료 기준과 결정할 정책

## 열기와 공유

웹 링크를 열면 로그인 없이 읽을 수 있습니다. 문서의 `HTML 내려받기`로 저장하면 인터넷 연결 없이도 열 수 있습니다.

`index.html`은 글꼴을 포함한 단일 HTML 파일입니다. 편집 원본에서 생성한 뒤 Vercel 문서와 함께 갱신합니다. GitHub Pages는 `main` 브랜치의 루트에서 발행합니다.

## 참고

문서의 미정 항목은 확정 정책이 아닙니다. 프로토타입은 브라우저에서 구매·구독을 체험하며 실제 결제와 운영 전체 DB 출처 검색은 연결하지 않았습니다. 본문에 포함된 Pretendard 글꼴의 이용 조건은 [글꼴 라이선스](licenses/Pretendard-LICENSE.txt)를 참고하세요.
